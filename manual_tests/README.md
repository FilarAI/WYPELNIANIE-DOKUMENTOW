# Ręczne testy 15 dokumentów

Każdy folder ma plik obiegówki testowej, przykład poprawnego wyniku i scenariusz z brakującym polem. Dane są fikcyjne. Najpierw wgraj obiegówkę i wybierz jeden typ dokumentu; szczegółowe wartości i brakujące pole są w pliku JSON.

Jeśli scenariusz kończy się HTTP 400, sprawdź komunikat walidacji. Jeśli aplikacja generuje dokument, porównaj go z `03_wynik_z_brakiem.docx` i sprawdź, czy puste pole jest widoczne.

W każdym przebiegu wybierz pojedynczy typ dokumentu zgodny z nazwą folderu. Nie używaj tych danych do wniosków urzędowych.
